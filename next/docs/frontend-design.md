# フロントエンド設計

## 画面実装方針

`next/frontend` の画面実装は、原則として Client Components で行う。

このアプリケーションでは、タスク管理やプロジェクト管理の操作画面が中心になる。画面内の状態管理、フォーム入力、モーダル、一覧更新などのクライアント側の振る舞いを扱いやすくするため、画面単位では Client Components を基本とする。

Server Components の利用は、静的な表示やサーバー側で完結する処理が明確な場合に限定する。

## ユーザー関連ページ

profile、auth、payment、settings などのユーザー関連ページは、現時点では機能実装を深追いしない。

このアプリケーションは学習用の Todo / プロジェクト管理アプリであり、主な学習対象はログイン、プロジェクト管理、目標設定、タスク管理である。ユーザー設定、支払い、詳細なプロフィール管理などは本質的な機能ではないため、必要に応じて外観や導線のサンプルに留める。
